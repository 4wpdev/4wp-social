# 0006. Щоденні метрики в своїй таблиці, одна панель для всіх мереж
Дата: 2026-11-22 · Статус: Прийнято

## Контекст
Аналітика показувала лише останній знімок за 28 днів. Автор хоче фільтр періоду, порівняння, tooltip і сортування. API мереж віддають різну глибину історії: YouTube — будь-який період, Meta / TikTok — обмежене вікно (≈ 90 днів), старіші дані втрачаються.

## Рішення
- Таблиця `{prefix}forwp_social_metrics`: `platform + day + item` → JSON метрик. Зберігаються лише щоденні підсумки, не сирі відповіді.
- Джерело, що вміє щоденні дані, реалізує `Analytics_Daily_Interface` (`daily()`, `metrics()`, `items()`, `item_columns()`).
- Щоденний cron і «Fetch now» перезаписують останні 7 днів (платформи доповнюють дані із запізненням). Перший запуск довантажує історію (`history_days()`).
- Фільтр періоду читає з таблиці. Список елементів (відео) за період і топ за день — запит до API з кешем на добу.
- Одна панель `views/partials/analytics-panel.php`: header (період + Fetch now), плитки з ▲/▼ проти попереднього періоду, діаграма з tooltip і топом за день, таблиця з сортуванням.
- Перша мережа — YouTube; інші підключаються тим самим інтерфейсом.

## Наслідки
- Історія накопичується з першого запуску; для Meta / TikTok старіше за вікно API не з'явиться.
- Знімок `forwp_social_analytics_snapshots` лишається для підсумків каналу і сирого JSON.
