# 0005. Окрема дата на мережу і «Already on …?» для всіх мереж
Дата: 2026-11-17 · Статус: Прийнято

## Контекст
Пост виходить в усі мережі в одну дату (дата поста + затримка з meta.json). Автор хоче задавати дату окремо для кожної мережі й позначати, що пост уже є в мережі, не лише для YouTube.

## Рішення
- API-мережі: поле `datetime-local` біля мережі в «4WP Social Media». Нова задача отримує цей `run_at`; задача в `queued` переноситься через `POST forwp-social/v1/jobs/{id}/schedule`. Дата не може бути раніше дати поста (`Posting_Service::not_before_publish()`).
- Ручні мережі: дата плану через `POST forwp-social/v1/plan` → `Status_Index` (`run_at`, `run_at_fixed=1`). Під час синхронізації з meta.json дата, задана вручну, зберігається. Якщо дату очистити, знову діє «дата поста + затримка».
- «Already on {мережа}?» для всіх готових мереж: посилання на пост → `crosspost/published` (як «Mark as published»). «Find by title» лишається тільки для YouTube.
- Link видаляє `queued`-задачу цієї мережі, щоб не було дубля.

## Наслідки
- У meta.json дата, задана вручну, не записується; вона живе лише в індексі на сайті.
- Час — у часовому поясі сайту.
