# 0008. TikTok Direct Post лише з явним вибором автора
Дата: 2026-11-25 · Статус: Прийнято

## Контекст
Для аудиту Direct Post TikTok вимагає UX за Content Sharing Guidelines: акаунт з `creator_info`, прев'ю, редагована назва, видимість без значення за замовчуванням, взаємодії вимкнені за замовчуванням, розкриття комерційного контенту, текст згоди. Плагін обирав видимість сам (`resolve_privacy`) і брав взаємодії з meta.json.

## Рішення
- Панель TikTok у метабоксі поста (показується, коли TikTok обрано): `GET forwp-social/v1/tiktok/creator` дає акаунт, `privacy_level_options`, заборонені взаємодії, ліміт тривалості, підпис і прев'ю відео.
- Вибір автора йде в опції завдання `tiktok` (`TikTok_Adapter::sanitize_options()`), далі в `Media_Package::tiktok()`.
- `TikTok_Adapter::publish()` публікує лише з цим вибором; без нього — помилка без повтору «choose TikTok settings in the post box». Автоматичний вибір видимості більше не використовується.
- Branded content не може бути приватним (UI і сервер).

## Наслідки
- Автопублікація TikTok з meta.json без відкриття поста більше не працює — лише кнопкою в метабоксі (за вимогами TikTok).
- Старі завдання TikTok без вибору (Retry) падають з поясненням.
