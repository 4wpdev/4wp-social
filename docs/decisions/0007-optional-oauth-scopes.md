# 0007. Необов'язкові OAuth scopes TikTok вмикаються вручну
Дата: 2026-11-25 · Статус: Прийнято

## Контекст
Плагін завжди просив 5 scopes TikTok. Затверджений Production-застосунок має лише `user.info.basic`, `video.publish`, `video.upload`. TikTok відмовляє у вході з помилкою `scope` на своїй сторінці й не повертає її на сайт — плагін не може її показати.

## Рішення
- Обов'язкові (`REQUIRED_SCOPES`): `user.info.basic`, `video.publish` — завжди.
- Необов'язкові (`OPTIONAL_SCOPES`): `user.info.profile`, `user.info.stats`, `video.list` — чекбокси в кроці 2 («Paste the app keys»), за замовчуванням вимкнені.
- Крок 3 показує, які scopes попросить наступне підключення; після підключення — отримані scopes (як і раніше).
- Аналітика TikTok без потрібних scopes повертає помилку з переліком відсутніх, без запиту до API.

## Наслідки
- Публікація працює з будь-яким затвердженим застосунком.
- Аналітику TikTok вмикають після рев'ю Display API scopes: чекбокси → Reconnect.
