# 0002. Локальний індекс статусів
Дата: 2026-11-04 · Статус: Прийнято

## Контекст
`forwp_drive_package` читає meta.json з GitHub (кеш 60 с). Для списку постів це N запитів.

## Рішення
Статуси всіх платформ зберігаються в `_forwp_social_status`. Список і календар читають лише його.

## Наслідки
Індекс оновлюється на імпорті, публікації, відмітці manual.
